## Iris

Iris autofarm, bag, profile and chat rankings.

### Installation

```
.ld https://raw.githubusercontent.com/sepiol026-wq/GoyModules/main/iris.hmod
```

### Commands

`irf [on/off]`, `iris`, `irlogs [count/date]`, `irbag`, `irprofile`, `irsupertop`, `irdaytop`, `irreset`

Replace `.` with your configured Hotaru prefix.
