## Vector

Vector module search and collections.

### Installation

```
.ld https://raw.githubusercontent.com/sepiol026-wq/GoyModules/main/vector.hmod
```

### Commands

`vector [query]`, `vecupdate [-f]`, `vecdl [slug/URL]`, `vecme`

Replace `.` with your configured Hotaru prefix.

Vector also indexes Heroku modules. Hotaru installs only genuine `.hmod` sources; `.py` files are not converted automatically.
