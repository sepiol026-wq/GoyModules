## Iris

Автофарм, мешок, профиль и топы Iris.

### Установка


### Команды

`irf [on/off]`, `iris`, `irlogs [count/date]`, `irbag`, `irprofile`, `irsupertop`, `irdaytop`, `irreset`

Префикс `.`, если он изменён в Hotaru, замени его своим.
