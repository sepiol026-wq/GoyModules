## RedConstructor

Module editor and constructor.

### Installation

```
.ld https://raw.githubusercontent.com/sepiol026-wq/GoyModules/main/redconstructor.hmod
```

### Commands

`rcbm`, `rchp`, `rcls`, `rcpg`

Replace `.` with your configured Hotaru prefix.
